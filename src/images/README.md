# images

Coloca aquí las imágenes del proyecto (logo, avatar del autor, imagen del hero,
iconos SVG optimizados, etc.).

Recomendaciones:

- Optimiza los SVG (por ejemplo con SVGO) antes de importarlos.
- Importa las imágenes en los componentes para que Vite las procese:
  `import avatar from '../../images/avatar.jpg';`
- Usa formatos modernos (WEBP/AVIF) cuando sea posible para reducir el peso.
